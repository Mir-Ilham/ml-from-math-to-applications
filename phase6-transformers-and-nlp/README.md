# 📘 Phase 6: Transformers & Natural Language Processing (NLP)

This phase focuses on modern **sequence modeling techniques** using Transformers and builds a strong foundation in **Natural Language Processing (NLP)**. It covers attention mechanisms, transformer architectures, and end-to-end NLP pipelines.

---

## 🧠 Transformers

This section introduces the evolution of sequence models and the Transformer architecture.

### 📊 Topics Covered

- **Preliminaries**
  - History of sequence models
  - Seq2Seq architectures
  - Attention mechanism overview

- **Transformer Introduction**
  - Motivation behind Transformers
  - Limitations of RNNs and CNNs for sequences

- **Self-Attention**
  - Scaled dot-product attention
  - Query, Key, Value representation
  - Multi-head attention

- **Transformer Components**
  - Encoder and Decoder architecture
  - Positional encoding
  - Feed-forward networks
  - Residual connections and layer normalization
