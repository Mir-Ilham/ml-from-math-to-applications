# 📘 Phase 5: Convolutional Neural Networks (CNNs), OpenCV & Recurrent Neural Networks (RNNs)

This phase focuses on learning **Computer Vision** using OpenCV and Convolutional Neural Networks (CNNs), along with **Sequential Models** such as RNNs, LSTMs, and GRUs.

---

## 🧠 OpenCV

This section introduces fundamental image processing techniques required for computer vision tasks.

### 📊 Topics Covered

- **Image I/O and Basic Operations**
  - Reading and writing images
  - Image display and manipulation

- **Image Transformations**
  - Resizing, cropping, rotating
  - Geometric transformations

- **Color Space Conversions**
  - RGB, Grayscale, HSV

- **Edge Detection and Filtering**
  - Sobel, Canny edge detection
  - Blurring and smoothing techniques

- **Contours and Object Detection Basics**
  - Contour detection
  - Shape analysis

## 🧠 Convolutional Neural Networks (CNN)

This section covers CNN architectures and their application in image-based tasks.

### 📊 Topics Covered

- **CNN Basics**
  - Convolution operation
  - Padding and stride
  - Pooling layers
  - Activation functions

- **Backpropagation in CNN**
  - Gradient flow in convolution layers
  - Filter weight updates

- **Project: Cat vs Dog Classification**
  - Dataset preparation
  - Model training and evaluation

- **Data Augmentation**
  - Flipping, rotation, scaling
  - Improving generalization

- **Pretrained Models**
  - Transfer learning
  - Fine-tuning pretrained CNNs

- **CNN Filter and Feature Map Visualization**
  - Visualizing learned filters
  - Interpreting feature maps

## 🧠 Recurrent Neural Networks (RNN)

This section introduces sequence modeling and architectures for temporal data.

### 📊 Topics Covered

- **RNN Basics**
  - Sequential data representation
  - Hidden states and time steps
  - Vanishing and exploding gradients

- **LSTM (Long Short-Term Memory)**
  - Input, forget, and output gates
  - Cell state mechanism

- **GRU (Gated Recurrent Unit)**
  - Update and reset gates
  - Comparison with LSTM

- **Advanced RNN Architectures**
  - Bidirectional RNN
  - Stacked RNN
  - Encoder-Decoder models
